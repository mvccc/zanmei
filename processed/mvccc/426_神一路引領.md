# 神一路引領

## (1)
陰涼  
的青草地，  
肥美的原野，  
神引  
領祂兒  
女前行；  
清  
涼  
的溪水旁，  
供人能安歇，  
神引  
領祂兒  
女前行。  

## (1)
或  
經過  
狂波，  
或  
經  
深  
淵  
，  
或  
經  
烈火，  
全靠主恩典；  
或  
憂傷  
痛苦，  
主安慰我心，  
不  
論  
是  
晝  
夜，  
神一路引  
領  
。
